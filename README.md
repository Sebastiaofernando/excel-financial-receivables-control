# excel-financial-receivables-control
Financial accounts receivable and delinquency tracking project using Microsoft Excel, IF, DATEDIF, SUMIF, SUMIFS, and COUNTIFS.

# Financial Accounts Receivable & Delinquency Control

## Overview

This project demonstrates how Microsoft Excel can be used to monitor accounts receivable, track overdue invoices, and support financial control through formulas and financial indicators.

## Business Objective

The objective is to organize customer invoices, identify payment status, calculate overdue days, and monitor outstanding balances. The dataset is fictional and intended for educational purposes.

## Tools and Functions

- Microsoft Excel
- IF: identifies whether an invoice has been paid
- DATEDIF: calculates the number of days between dates
- TODAY: updates overdue calculations based on the current date
- SUM: calculates total invoiced amounts
- SUMIF: calculates amounts received based on payment status
- SUMIFS: calculates overdue outstanding amounts using multiple criteria
- COUNTIFS: counts overdue unpaid invoices

## Key Metrics

- Total invoiced
- Total received
- Total outstanding
- Number of overdue unpaid invoices
- Total overdue amount

## Business Value

The project helps organize receivables, identify overdue payments, and provide a clearer view of expected cash inflows. It demonstrates the application of spreadsheet formulas to a practical financial-control scenario.

## Data Disclaimer

All customer names, invoice numbers, dates, and amounts used in this project are fictional and for educational purposes only.
